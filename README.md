# RAIN DROPS

`pygame`로 만든 빗방울 테마 리듬게임입니다.
실제 음악 파일 재생, BPM 기반 차트 동기화, 물방울 노트, 홀드 노트, 난이도 선택, 시작 화면과 곡 선택 UI까지 포함되어 있습니다.

## 포함된 기능

- 실제 `wav` 음악 파일 2곡 재생
- BPM 기준으로 만든 노트 차트와 판정선 동기화
- 물방울 모양 일반 노트와 홀드 노트 지원
- `Normal`, `Hard` 난이도 선택
- `시각 보정`, `판정 보정` 옵션 화면
- 시작 화면, 곡 선택 화면, 결과 화면 제공
- `PERFECT`, `GREAT`, `GOOD`, `BAD`, `MISS` 판정 제공
- 점수, 콤보, 최대 콤보, 정확도 표시

## uv로 실행 환경 만들기

```bash
uv sync
```

위 명령을 실행하면 `.venv`가 생성되고 필요한 패키지가 설치됩니다.

## 실행

```bash
uv run main.py
```

## 조작 방법

- `↑`, `↓`: 곡 선택
- `←`, `→`: 난이도 선택
- `Enter`, `Space`: 시작 또는 다음 화면 이동
- `O`: 타이밍 옵션 화면 열기
- 게임 중 `←`, `↓`, `↑`, `→`: 노트 입력
- 홀드 노트: 시작 지점에서 누른 뒤 끝까지 유지
- `R`: 결과 화면에서 같은 곡 다시 시작
- `Esc`: 게임 중 메뉴로 복귀, 메뉴에서는 종료

## 판정 기준

- 판정선은 하늘과 바닥의 경계선입니다.
- 물방울 노트가 그 경계선에 얼마나 정확히 닿는지에 따라 `PERFECT`, `GREAT`, `GOOD`, `BAD`, `MISS`가 결정됩니다.

## 타이밍 옵션

- `시각 보정`: 메트로놈 소리와 발광 네모가 정확히 맞도록 화살표키로 조절합니다.
- `판정 보정`: 7번 테스트하여 플레이어가 빠르게 누르는지, 늦게 누르는지 측정하고 게임 판정에 반영합니다.

## 곡 구성

- `Pulse Drive`
  - BPM 128
  - 비교적 정직한 4비트 중심 패턴
- `Neon Step`
  - BPM 140
  - 더 빠르고 엇박이 섞인 패턴

실제 오디오 파일은 `assets` 폴더에 들어 있습니다.

## 파일 구조

- `main.py`: 실행 진입점
- `game_app.py`: 게임 로직 전체
- `assets/pulse_drive.wav`: 데모 곡 1
- `assets/neon_step.wav`: 데모 곡 2
