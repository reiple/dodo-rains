# WoW풍 오토배틀러 데모 기능 명세서

## 1. 목표
- Unity로 친구 시연용 오토배틀러 데모를 만든다.
- 장르는 전략적 팀 전투 스타일의 오토배틀러로 잡는다.
- 이번 버전은 배포용이 아니라 플레이 가능한 데모 버전이다.
- 핵심은 배치, 상점, 시너지, 자동 전투, 라운드 진행을 보여주는 것이다.

## 2. 데모 목표 경험
- 플레이어는 준비 단계에서 골드를 사용해 유닛을 구매한다.
- 구매한 유닛을 벤치 또는 보드 하단 3열에 배치한다.
- 전투 시작 버튼을 누르면 자동 전투가 시작된다.
- 유닛은 자동으로 이동, 공격, 스킬 사용을 수행한다.
- 전투 종료 후 다음 라운드로 넘어가며 다시 상점을 이용한다.

## 3. 포함 기능
- 7 x 6 헥사형 전장
- 하단 3열 플레이어 배치 구역
- 상단 3열 적 스폰 구역
- 8칸 벤치
- 5칸 상점
- 골드 소모 및 상점 새로고침
- 유닛 구매 및 배치
- 유닛 이동 및 보드 내 자리 교체
- 유닛 벤치 복귀
- 자동 전투
- 진영/직업 시너지 계산
- 동일 유닛 3개 조합 시 승급
- 라운드별 적 웨이브 생성

## 4. 제외 기능
- 멀티플레이
- 카로셀
- 아이템 조합
- 증강체
- 저장/불러오기
- 정식 캐릭터 모델, 애니메이션, VFX

## 5. 게임 루프
1. 준비 단계 시작
2. 상점 표시
3. 유닛 구매
4. 벤치와 보드 배치 정리
5. 전투 시작
6. 적 웨이브 생성
7. 자동 전투 진행
8. 승패 판정
9. 골드 보상 획득
10. 다음 라운드 진입

## 6. 경제 규칙
- 시작 골드: 10
- 승리 보상: 5
- 패배 보상: 3
- 상점 새로고침 비용: 2
- 유닛 구매 비용: 코스트와 동일

## 7. 전투 규칙
- 각 유닛은 한 칸을 점유한다.
- 가장 가까운 적을 우선 타겟으로 잡는다.
- 사거리 밖이면 이동하고 사거리 안이면 공격한다.
- 마나가 가득 차면 스킬을 사용한다.
- 한쪽 팀이 전멸하면 전투가 끝난다.

## 8. 성공 기준
- 친구에게 직접 시연 가능한 한 판 루프가 완성된다.
- 상점, 배치, 전투, 시너지의 흐름이 눈에 보인다.
- 3개 조합 승급이 실제로 작동한다.
- 플레이스홀더 그래픽만으로도 장르 감이 전달된다.
